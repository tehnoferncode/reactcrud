# React Mini CRUD Dashboard (Real-World Style)

This project demonstrates a **real-world CRUD (Create, Read, Update, Delete)**
dashboard built using **React only**, without any backend.

It is designed for students and beginners to understand how **actual admin
panels work internally** using state management.

---

## 🚀 What This Project Covers

- Create users using a form
- Read users in a dashboard table
- Update users using Edit mode
- Delete users with confirmation
- Search users (name, email, role)
- Persist data using localStorage
- Clean admin-style UI

---

## ❌ What This Project Does NOT Do

- No page reload
- No fake static list
- No backend dependency

👉 Everything works using **React state**, just like frontend interview tasks.

---

## 🌍 Real-World Use Case

This pattern is commonly used in:
- Admin panels
- Internal tools
- Interview assignments
- Dashboard prototypes
- Frontend CRUD tasks

---

## 🧠 Concepts You Will Learn

- Controlled forms in React
- State-based CRUD logic
- Conditional rendering (Add vs Edit)
- List rendering and updates
- Search & filtering with `useMemo`
- LocalStorage persistence
- Clean component structure
